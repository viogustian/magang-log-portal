# Agent Guidelines

## Agent skills

### Issue tracker

Issues and specs are tracked locally as Markdown files in `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles mapped to local issue statuses. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo using `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
